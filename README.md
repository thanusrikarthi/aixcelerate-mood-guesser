 Happy and Sad Sentence Guesser

 This is a simple Python program that predicts whether a sentence is Happy or Sad.

 Features
 Counts Happy and Sad sentences.
 Checks words in a sentence.
 Predicts the mood.
 Calculates accuracy using practice sentences.

 Result
 The program achieved 80% accuracy in Level 3.

 Learning Questions
 "good party today" = Happy (+3).
 "bad exam day" = Sad (-3).
 "exam" = 0 because it appears equally in both moods.
 "not good" is predicted as Happy because the program does not check negative words.
